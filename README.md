# Rock Paper Scissors Game

A console-based Rock Paper Scissors game built with C++.

## Description

This project is a multi-round Rock Paper Scissors game where the player competes against the computer.

The player chooses Rock, Paper, or Scissors, while the computer generates its choice randomly. The program determines the winner of each round and displays the final game results.

## Features

* Choose the number of rounds (1–10)
* Player vs Computer gameplay
* Random computer choices
* Round-by-round winner detection
* Tracks:

  * Player wins
  * Computer wins
  * Draws
* Displays the final game winner
* Option to play again
* Different console colors for the final result

## Technologies

* C++
* Enums
* Structs
* Functions
* Arrays
* Loops
* Conditional statements
* Random number generation

## How to Run

1. Clone the repository.
2. Open the project in a C++ development environment.
3. Compile `Rock_Paper_Scissor.cpp`.
4. Run the generated executable.
5. Choose the number of rounds and play against the computer.
